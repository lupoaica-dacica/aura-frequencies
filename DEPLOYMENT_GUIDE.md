# Aura Frequencies - Azure Static Web Apps Deployment Guide

## Prerequisites

Before deploying, ensure you have:
- ✅ Node.js v18+ installed (you have v26.8.1)
- ✅ Project built (`npm run build`)
- ✅ Azure subscription (free tier available)
- ✅ GitHub repository (https://github.com/lupoaica-dacica/aura-frequencies)
- ✅ Git repository cloned locally

## Deployment Methods

### Method 1: GitHub Actions (Recommended - Automated CI/CD)

**Best For:** Continuous deployment on every push to main branch

#### Steps:

1. **Create Azure Static Web App Resource:**
   ```powershell
   # Option A: Via Azure Portal
   # 1. Go to https://portal.azure.com
   # 2. Click "Create a resource"
   # 3. Search for "Static Web App"
   # 4. Click Create
   # 5. Fill in details:
   #    - Name: aura-frequencies
   #    - Region: Choose nearest to you
   #    - GitHub repository: lupoaica-dacica/aura-frequencies
   #    - Branch: main
   #    - Build presets: Custom
   #    - App location: .
   #    - API location: (leave empty)
   #    - Output location: dist
   # 6. Review and Create
   ```

2. **GitHub Actions Workflow (Auto-generated by Azure):**
   - Azure will automatically create `.github/workflows/azure-static-web-apps-*.yml`
   - Workflow triggers on push to `main` branch
   - Automatically builds and deploys your app

3. **Done!** 
   - Every time you push to GitHub, it auto-deploys
   - Check GitHub Actions tab to see deployment status

### Method 2: Static Web Apps CLI (Local Deployment)

**Best For:** Manual deployment from your machine

#### Step 1: Install Azure CLI and SWA CLI

```powershell
# Install Azure CLI
winget install Microsoft.AzureCLI

# Or using Chocolatey:
choco install azure-cli

# Or download from: https://aka.ms/azure/azure-cli
```

#### Step 2: Install Static Web Apps CLI

```powershell
npm install -g @azure/static-web-apps-cli

# Or use npx without installing:
npx @azure/static-web-apps-cli@latest --version
```

#### Step 3: Login to Azure

```powershell
azure-cli login
# Browser will open, authenticate with your Azure account
```

#### Step 4: Create Azure Static Web App

```powershell
az staticwebapp create \
  --name aura-frequencies \
  --resource-group myResourceGroup \
  --source https://github.com/lupoaica-dacica/aura-frequencies \
  --location "West US 2" \
  --branch main
```

#### Step 5: Deploy

```powershell
# Build first (if not already done)
npm run build

# Deploy using SWA CLI
npm run deploy

# Or use SWA CLI directly:
npx @azure/static-web-apps-cli deploy ./dist \
  --deployment-token YOUR_DEPLOYMENT_TOKEN
```

### Method 3: GitHub CLI (Alternative)

## Project Configuration Reference

### swa-cli.config.json
```json
{
  "configurations": {
	"pwa-starter": {
	  "appLocation": ".",           // Root directory
	  "outputLocation": "dist",      // Build output (Vite)
	  "appBuildCommand": "npm run build --if-present",
	  "run": "npm start",
	  "appDevserverUrl": "http://localhost:3000"
	}
  }
}
```

### public/staticwebapp.config.json
```json
{
  "navigationFallback": {
	"rewrite": "index.html",  // Routes to index.html for SPA
	"exclude": ["*.{css,js,mjs,ts,png,gif,ico,jpg,svg,json,woff2,ttf}"]
  }
}
```

## Troubleshooting

### Issue: "Build failed"
```
✅ Solution: Ensure npm run build works locally first
npm run build
```

### Issue: "Routes not working (404)"
```
✅ Solution: staticwebapp.config.json has navigationFallback
Verify /public/staticwebapp.config.json exists and is correct
```

### Issue: "Deployment token invalid"
```
✅ Solution: Get new token from Azure Portal
Portal → Your Static Web App → Deployment tokens
```

### Issue: "Service Worker not loading"
```
✅ Solution: Check dist/sw.js is generated
Ensure Workbox PWA plugin is configured in vite.config.ts
```
